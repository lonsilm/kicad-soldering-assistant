# v1.1.0 验证

在 Windows、KiCad 10.0.6 环境完成以下验证。测试报告和生成的工程数据仅保存在本机 `tests/results/`，不提交到仓库。

- 编译为 Windows GUI 子系统的单个 EXE；复制到仅有这一文件的新文件夹后正常运行。
- 路径包含中文、空格、单引号和 `&` 时，仍可读取工程和生成页面。
- 完成合成板以及两个真实工程的只读生成；生成前后源文件 SHA256 一致。
- 待焊清单正确排除 DNP、显式不计入 BOM 的器件和机械对象。
- 内置运行缓存被改坏后，EXE 能从自身资源恢复并成功生成。
- 同一工程重新生成保持输出标识，最近记录不重复。
- 多板目录要求选择目标；路径不存在或文件类型不支持时显示错误。
- 实际由 EXE 生成的 HTML 已用 Headless Edge/Playwright 验证：位号定位、进度保存与重载、JSON备份恢复、正反面切换、1280px窗口布局和零外部网络请求。

`.github/workflows/build-windows.yml` 提供手动构建入口，不会自动执行上述需要本机 KiCad 的实板测试。
